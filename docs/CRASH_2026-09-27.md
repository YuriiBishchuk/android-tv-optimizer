## Висновок

Це був `system_server` в рестарт-лупі, а не цегла. Тригер — `SettingsAndroidActivity`
Projectivy. Правило: без потреби туди не заходити (див. README п.5).

Страховка: `launcherx` enabled як fallback, щоб наступний такий краш мав куди впасти.
Діагностика наступного разу: `./scripts/boot-diag.sh`.
